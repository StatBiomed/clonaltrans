## Model data and Checkpoints

This page contains the above information for two datasets (the human cord blood and the mouse hematopoiesis system as mentioned in the manuscript) generated by CLADES. 

Specifically, it contains the relevant configuration files, model checkpoints for both the constant and the dynamic modes, synthetic datasets, bootstrapping results and the comprehensive Gillespie simulation files. 

They are deposited and can be accessed via [figshare](https://figshare.com/articles/dataset/CLADES/27908142) with [DOI number](10.6084/m9.figshare.27908142), due to the extreme large amount of data files (bootstrapping and Gillespie simulations).
