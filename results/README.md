## Model data and Checkpoints

This page contains the above information for two datasets (the human cord blood and the mouse hematopoiesis system as mentioned in the manuscript) generated by CLADES. 

Specifically, it contains the relevant configuration files, and model checkpoints for both the constant and the dynamic modes. As for other datasets or analysis, that requires a large number of files, such as the synthetic dataset or the bootstrapping results, they are deposited and can be accessed via [figshare](https://figshare.com/articles/dataset/CLADES/27908142) with [DOI number](10.6084/m9.figshare.27908142).
